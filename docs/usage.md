# Usage

```python
import oceanography_tutor
```

Each module is self-contained; see docstrings for the API:

- `oceanography_tutor.flashcard` — Flashcard model and operations
- `oceanography_tutor.tutor` — Spaced repetition trainer logic
- `oceanography_tutor.tracker` — Progress tracking and storage
- `oceanography_tutor.data` — Tide, current, and salinity data models and access
- `oceanography_tutor.cli` — Command-line interface for tutor and tracker
- `oceanography_tutor.tests` — Unit tests for the entire application
